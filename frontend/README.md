# Frontend (SPA)

Vue 3 + Vite SPA. В разработке используется dev-server (порт 5173 по умолчанию), в контейнере — nginx, который отдаёт статические файлы из `dist/`.

Особенности:
- В `src/api/index.js` собраны HTTP-обёртки для всех основных API-префиксов (`/api/auth`, `/api/teacher`, `/api/student`).
- В `vite.config.js` есть прокси для пути `/api` на время разработки — удобство при локальной работе с бэкендом.
- Nginx конфигурация (`nginx.conf`) проксирует `/api` на `api-gateway` внутри Docker-сети.

Ключевая переменная окружения: `VITE_API_BASE_URL` (определяет базовый путь к API для сборки).
