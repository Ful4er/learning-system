# Eureka Server

Роль: центра регистрации и обнаружения сервисов в кластере. Нужен для динамической маршрутизации через `api-gateway` и мониторинга доступности экземпляров.

Порт: 8761 (по умолчанию)

Особенности и примечания:
- В продакшен стоит внимательно настроить `enable-self-preservation` и параметры репликации, чтобы избежать ложных удалений сервисов.
- В `application.yml` указаны настройки таймаутов и health-check параметров — можно откорректировать под реальные окружения.

Переменные окружения/конфигурация: `EUREKA_SERVER_URL` и соответствующие свойства `eureka.client.*`.
